# 📦 Versioning Standards

This repository follows semantic versioning.

| Version Type | Description |
|---|---|
| Major | Breaking changes or major architectural changes |
| Minor | New functionality and feature additions |
| Patch | Fixes, optimisations, maintenance, and documentation updates |

---

## Version Examples

```text
v1.0.0
v1.1.0
v1.1.1
```

---

## Semantic Structure

```text
1.4.2
│ │ │
│ │ └── Patch
│ └──── Minor
└────── Major
```
